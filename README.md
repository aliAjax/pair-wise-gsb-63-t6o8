# 游乐设施日常检验与缺陷闭环平台

基于 Vue3、Naive UI、Pinia、Vue Router、TanStack Query、Axios、WebSocket 和 Vite 的独立前端工程。数据默认保存在 localStorage，无需后端即可演示。

## 功能

- **标准发布（按设备型号系列版本化）**：新标准只对发布之后开始的任务生效；任务开始时把当版逐项限值快照冻结，在途任务始终按开始时那版判定，不串用新标准。
- **检验任务**：列表筛选、统计概览；新建任务自动固定到当前已发布最新版本；该型号无适用标准的任务直接进入「待复核」，可人工指派标准。
- **旧记录迁移**：按设备型号（设备编号前缀）补挂该系列默认（首版）标准并按该版重新判定；无适用版本的旧记录转入待复核。
- **并发保存与冲突修订**：每次保存带乐观锁修订号（R 基线）。两窗口先后保存时，后保存者保留自己的全部输入并生成「冲突修订」；先保存窗口的责任人、处置结论、证据编号受保护不被覆盖，后保存意见可在修订上一键采纳。证据编号合并去重。
- **缺陷处置泳道**：待复核/需整改/整改中/待复测/停用/已关闭六列，按风险排序，显示固定标准版本、证据数与下一次复测安排。
- **复测放行闭环**：复测失败必须预约下一次复测、设备继续停用；复测通过后状态关闭，需再经「恢复开放」确认才能解除停用（前置校验：最近一次复测必须通过）。
- **判定依据追溯**：详情页底部完整呈现「标准版本 → 修订链（含冲突修订与先保存快照）→ 历次复测记录」，审计时间线可直接跳回记录依据链。
- JSON 记录导出。

## 演示路径

1. 「标准发布」页可见 AM 系列 V1（旧记录默认版）与 V2（2026-09-29 07:30 发布，磨损限值收紧至 4.0 mm）。
2. 总览中 `INS-240929-01`（V2 发布后开始）实测 4.4 mm 按 V2 判异常；`INS-240821-01`（在途）限值仍是 V1 的 ≤5.0 mm。
3. 打开任意记录，点「模拟另一窗口先保存」后再点「保存」，即产生冲突修订并展示双方字段保护结果。
4. `INS-240928-09` 已含一次失败复测（继续停用，下次复测 2026-09-29 14:00）；登记通过复测后「恢复开放」按钮才可用。
5. `INS-240821-04`（WF 摩天轮）无适用标准，迁移后处于待复核。

## 启动

```bash
npm install
npm run dev
```

访问 `http://localhost:18463`。

## 构建与规则验证

```bash
npm run build    # vue-tsc 类型检查 + 产物构建
npm run verify   # 运行领域规则脚本（版本固定/冲突修订/回填/复测闭环共 38 项断言）
```
